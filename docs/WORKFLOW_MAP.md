# End-to-End Workflow Map

## Confirmed order path
Confirmed Order/Job
→ Merch file / shared Job master
→ IE task + IE Bulletin
→ Planning Ready gate
→ T&A plan
→ Central line plan / Gantt
→ upstream readiness and material processes
→ Cuttable eligibility
→ Daily Cut Plan
→ Cutting
→ Print / Embroidery / Special process when required
→ Ready for Input
→ Sewing / actual line progress
→ Quality / End-line / Final inspection
→ Finishing / Packing
→ Shipment / Export
→ Job 360 history and KPI.

## Upstream fabric/material path
Projection (early only)
→ Yarn / Yarn Dyeing / Purchase
→ Knitting
→ Greige Store
→ Dyeing
→ optional AOP / Brush / Peach / other post-dye process
→ Lab / testing / QA release where required
→ Finished Fabric
→ Cutting.

## Sample path
Sample work may start before order confirmation.
- Knitting, Dyeing, Printing, Embroidery own and enter their own sample work.
- Central Sample Department separately handles sample Cutting, Sewing, Finishing and final delivery.
- PP Sample status flows to line input/shipment follow-up.

## Planning change-control
Baseline Plan
→ Floor actual/proposed change
→ Change Request
→ Central Planner accepts/rejects
→ Revised Plan version
→ downstream recalculation
→ shipment risk / required-hours simulation
→ Revised Plan
→ Actual.
