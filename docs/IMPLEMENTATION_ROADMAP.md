# Implementation Roadmap

## Phase 0 — Handoff / technical validation
- IT reviews architecture, security, database and deployment choices.
- Confirm local Windows + Docker development standard.
- Create private GitHub repository and branching policy.

## Phase 1 — Foundation
- Auth, roles/permissions, audit
- Factory/Floor/Line/Machine masters
- Buyer and core masters
- Task/workflow engine
- Global shell/search

## Phase 2 — Order / Merchandising
- Full manual order entry
- Buyer PO importer/mappings
- Projection
- Merchandising task/follow-up

## Phase 3 — Upstream material
- Yarn/Yarn Dyeing/Purchase
- Knitting
- Greige Store
- Dyeing
- Lab/Testing
- Fabric finishing / AOP / Brush / Peach
- Finished Fabric Store

## Phase 4 — Pre-production
- Sample modules
- CAD/Pattern/Size Set
- IE Bulletin
- T&A engine

## Phase 5 — Planning
- Central Gantt
- Capacity balancing
- working-hours simulation
- Floor Planner change requests
- plan versions and actual overlay
- subcontract

## Phase 6 — Cutting / value-add
- Cuttable and Input Coverage
- Daily Cut Plan
- Cutting execution
- Printing / Embroidery / Sequins / Wash

## Phase 7 — Sewing / Quality
- line input follow-up
- actual sewing production
- live DHU/OQL/defect entry and dashboards
- pre-final/final/buyer inspection
- floor TV display

## Phase 8 — Finishing / Stores / Shipment
- finishing/poly/packing
- trims/accessories
- inventory/stores
- shipment/export/commercial

## Phase 9 — MIS / Job 360 / performance
- management dashboards
- job timeline/history
- cross-filter and drill-down
- notifications/escalation tuning

## Phase 10 — Pilot and optimization
- one floor / selected buyers pilot
- reconcile ERP vs existing Excel reports
- performance/security backup tests
- gradual rollout
- optimization/AI only after deterministic workflows are stable
