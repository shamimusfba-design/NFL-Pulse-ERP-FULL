# NFL Pulse ERP — Project Scope

NFL Pulse ERP is one connected garment-factory system covering confirmed Order Entry through upstream material/fabric processes, Sample/CAD/IE, Central Planning, production, quality, finishing and shipment, with Management/MIS and Job 360 above the operational modules.

The implementation principle is to preserve the factory's actual reports/fields and remove duplicate entry. Source departments enter actuals once; dependent departments receive the same data automatically. Each function has relevant Pending Tasks, reports and role/ownership controls.
