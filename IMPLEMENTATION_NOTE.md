# Implementation Note

Version 0.4.0 is the first single consolidated pilot package after the earlier incremental v0.3.x patches. Use this package as the new baseline rather than applying the old patches in sequence.

The requested Central Planning chain is included: bulk T&A draft generation → capacity heatmap review → T&A approval/release → automatic Sewing Gantt draft → Central Planning review/adjustment → official Gantt approval.

The package also includes removable 50-job connected demo data for workflow evaluation. Exact company Excel print layouts for Fabric Order Sheet, T&A and Work Order remain intentionally pending until the supplied source templates are received.
